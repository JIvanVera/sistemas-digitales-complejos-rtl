=== 🧪 LAB — Practical Exercises
**Implementing a 2-FF sync, an edge detect sync, and a pulse sync**

[.text-justify]
In this lab you will practice writing **synthesizable SystemVerilog** modules for different types of synchronizers.

[.text-justify]
**🎯 Goals**
* Implement a **2-FF synchronizer** module.
* Implement an **edge-detect synchronizer** module.
* Implement a **pulse synchronizer** module.

[.text-justify]
**🧰 Tools**
[.small-text]
* Use **EDAPlayground** → *SystemVerilog + Questa* or *Verilator* setup.  
* Observe how the output stabilizes a few cycles after input transitions.
